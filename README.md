# tngranados/homebrew-tap

```sh
brew tap tngranados/tap
brew install tngranados/tap/newest-files
brew install --cask tngranados/tap/font-nordwand-mono
```

| Name                 | Type    | Upstream                                                  |
| -------------------- | ------- | --------------------------------------------------------- |
| `newest-files`       | Formula | [tngranados/newest-files](https://github.com/tngranados/newest-files) |
| `font-nordwand-mono` | Cask    | [tywr/Nordwand-Mono](https://github.com/tywr/Nordwand-Mono) |

The `Bump` workflow checks upstream releases daily and updates versions and checksums.
